ConfigBackup 1.4.0 launcher help

Python must work before the launcher can make a machine report. No tests have run if this help page opened because Python is missing.

Run-SafeTests.cmd offers a visible Python 3.14 WinGet installer if no Python is found. Installation requires your choice. If WinGet is unavailable or installation fails, use your organization's approved Python 3.10+ installation. Reopen your terminal/launcher after installation if PATH discovery needs refreshing.

For a custom installation set CONFIGBACKUP_TEST_PYTHON to its full executable path in PowerShell:
$env:CONFIGBACKUP_TEST_PYTHON = 'C:\Approved\Python\python.exe'
.\Run-SafeTests.cmd

A selected but broken Python environment is not silently replaced. Remove an obsolete override or repair that environment through your approved process. Keep every kit file together and run from an extracted local folder.

When Python starts, the launcher can offer PyYAML, ruamel.yaml and tzdata in a new test environment and Git via WinGet, then rerun checks. You can decline and continue available tests. Windows roles/RSAT are never installed. Read LAUNCHER-GUIDE.txt for details, offline wheels and optional role captures.

Keep local results local. This page is help, not a test result.
