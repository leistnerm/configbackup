CONFIGBACKUP WINDOWS TEST KIT 1.5.0

Extract the complete kit to a local directory and run Run-SafeTests.cmd.
The launcher checks prerequisites, offers missing dependencies for review,
reruns checks and saves a local HTML report. Installation is optional.

Read WINDOWS-TESTING.md for platform limitations and LAUNCHER-GUIDE.txt for
launcher options. Offline fixtures use synthetic data. Optional GPO and
component reads do not change policies or provision roles. Database fault
and reconstruction tests require a separate disposable database environment.

The kit includes ConfigBackup 1.5.0 and GPO harness 1.0.0 with SHA256 sidecars.
Unavailable prerequisites or native Windows checks remain NOT RUN.
