# Setup and recovery details

Setup recovery and guided discovery preserve independent backup failure boundaries.

- Default related-configuration and generated-launcher history, explicit file selection and a completeness inventory.
- New private setup export, strict hash/path verification, rebuild checklist and disabled relocation candidates with launcher regeneration.
- Separate offline Python wheel bundles and compatibility checks; periodic disposable setup-recovery drills with retained JSON/HTML and monitoring telemetry.
- Local tool/service discovery, reviewed collector suggestions and explicit dependency installation with a fresh check.
- Scheduled-job file suggestions requiring individual selection; dynamic or inaccessible definitions remain unresolved.

Read [setup recovery](recovery-setup.md), [autodetection](autodetect.md), [configuration menus](configuration-editor.md), [validation](../VALIDATION.md). Existing database/Windows coverage limits remain. A passing offline recovery drill is not a native database restore or unattended-account access test.
